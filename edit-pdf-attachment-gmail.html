GUIDEПОСІБНИК

How to edit a PDF attachment in GmailЯк редагувати PDF-вкладення в Gmail

Most emailed PDFs need small changes, not a rewrite. Here is how to make those changes cleanly and send the result back where it belongs.Більшість PDF із пошти потребують дрібних змін, а не переписування. Ось як акуратно їх внести й повернути результат туди, де він потрібен.

Decide what kind of edit you needВизначте, яке редагування потрібне

Feedback on a draft calls for highlights and comments. A correction calls for new text, sometimes over a whiteout. Structural changes call for reordering, adding or deleting pages. Knowing which one you need keeps the edited file easy for the next person to read.Відгук на чернетку — це виділення й коментарі. Виправлення — новий текст, іноді поверх замазаного. Зміни структури — це перестановка, додавання чи видалення сторінок. Коли знаєте, що саме потрібно, наступній людині легше читати відредагований файл.

Annotate clearlyРобіть позначки зрозумілими

Highlight the exact phrase, not the whole paragraph, and keep each comment to one point. If you suggest new wording, write it in the comment. Use drawing sparingly, for layout or image feedback. The sender should understand every note without a follow-up call.Виділяйте точну фразу, а не весь абзац, і тримайте в кожному коментарі одну думку. Якщо пропонуєте інше формулювання, напишіть його в коментарі. Малювання використовуйте помірно — для зауважень щодо макета чи зображень. Відправник має зрозуміти кожну позначку без додаткового дзвінка.

Know the limits of whiteoutЗнайте межі замазування

Whiteout covers content visually so it does not show on the page. It is not certified redaction, and it should not be used to remove sensitive or confidential data. Large edits to scanned text are also limited, since scans are images rather than editable text. For heavy rewrites, ask for the source file.Замазування візуально приховує вміст, щоб його не було видно на сторінці. Це не сертифіковане видалення даних, і його не слід використовувати для прибирання чутливої чи конфіденційної інформації. Великі правки сканованого тексту теж обмежені, адже скан — це зображення, а не редагований текст. Для суттєвих змін попросіть вихідний файл.

Reply, and decide where the file livesВідповідайте й визначте, де зберігати файл

Reply in the same thread with the edited PDF. The original stays in the earlier message, so you can compare versions. If several people keep editing the same document, move it to Google Drive and work there. That avoids a pile of attachments with slightly different names.Відповідайте в тому самому ланцюжку з відредагованим PDF. Оригінал лишається в попередньому листі, тож версії можна порівняти. Якщо той самий документ редагують кілька людей, перенесіть його в Google Drive і працюйте там. Так ви уникнете купи вкладень із трохи різними назвами.

Pro tipsКорисні поради

  1. Add “edited” or “comments” to the file name before replying.Додайте до назви файлу «виправлено» чи «коментарі» перед відповіддю.
  2. Use one highlight colour for issues and another for questions.Використовуйте один колір виділення для проблем, інший — для запитань.
  3. Never rely on whiteout to hide passwords, IDs or financial data.Ніколи не покладайтеся на замазування, щоб приховати паролі, номери документів чи фінансові дані.
  4. For ongoing collaboration, keep the PDF in Google Drive.Для тривалої спільної роботи зберігайте PDF у Google Drive.

TROUBLESHOOTINGЯКЩО ЩОСЬ НЕ ТАК

If something does not workЯкщо щось не виходить

⚠ I cannot change the existing textНе вдається змінити наявний текст

If the PDF is a scan, the text is part of an image. Cover small areas with whiteout and type new text on top, or ask the sender for an editable source.Якщо PDF — це скан, текст є частиною зображення. Закрийте невеликі ділянки замазкою й надрукуйте новий текст поверх або попросіть у відправника редагований вихідний файл.

⚠ The whiteout box shows on a coloured backgroundЗамазку видно на кольоровому тлі

Whiteout is a white box, so it stands out on colour. Use a comment asking the sender to fix it in their source file instead.Замазка — це білий прямокутник, тож на кольоровому тлі її видно. Замість цього залиште коментар і попросіть відправника виправити вихідний файл.

⚠ I need to remove sensitive dataТреба прибрати чутливі дані

Whiteout is not certified redaction; the hidden content may still be recoverable. Do not rely on it for sensitive information and use a proper redaction process.Замазка не є сертифікованим видаленням даних: прихований вміст може лишатися доступним. Не покладайтеся на неї для чутливої інформації й використовуйте належний процес видалення.

⚠ The recipient does not see my commentsОдержувач не бачить моїх коментарів

Comments are part of the PDF, but some viewers show them in a side panel. Ask the recipient to open the comments or annotations list in their PDF viewer.Коментарі є частиною PDF, але деякі програми показують їх на бічній панелі. Попросіть одержувача відкрити список коментарів чи приміток у своєму переглядачі PDF.

⚠ The merged file is too large to openОб’єднаний файл завеликий

DocHub works with files up to 31 MB. Merge fewer pages or compress large scans before combining them.DocHub працює з файлами до 31 МБ. Об’єднуйте менше сторінок або стисніть великі скани перед об’єднанням.

Frequently asked questionsПоширені запитання

Does the sender see my comments?Чи бачить відправник мої коментарі?

Yes. Comments and highlights are part of the PDF you send back, so the recipient sees them when they open it.Так. Коментарі й виділення є частиною PDF, який ви надсилаєте, тож отримувач побачить їх, відкривши файл.

Is the original attachment changed?Чи змінюється початкове вкладення?

No. The attachment stays in the original email. You send a new, edited copy in your reply.Ні. Вкладення лишається в початковому листі. Ви надсилаєте нову, відредаговану копію у відповіді.

Can I edit the existing text in a scanned PDF?Чи можна редагувати наявний текст у сканованому PDF?

Large edits to scanned text are limited, because a scan is an image. You can add new text and use whiteout over small areas.Великі правки сканованого тексту обмежені, бо скан — це зображення. Ви можете додавати новий текст і замазувати невеликі ділянки.

Is whiteout the same as redaction?Чи замазування — це те саме, що видалення даних?

No. Whiteout covers content visually; it is not certified redaction. Do not use it to remove sensitive data.Ні. Замазування приховує вміст лише візуально; це не сертифіковане видалення даних. Не використовуйте його для прибирання чутливої інформації.

Can I combine the attachment with another PDF?Чи можна поєднати вкладення з іншим PDF?

Yes. You can merge PDFs and reorder, add or delete pages before sending the result.Так. Можна об’єднати PDF, а також змінити порядок, додати чи видалити сторінки перед надсиланням.

What file sizes are supported?Файли якого розміру підтримуються?

DocHub works with files up to 31 MB.DocHub працює з файлами до 31 МБ.

Can I sign after editing?Чи можна підписати після редагування?

Yes. Add your signature, initials and date in the same session, or request a signature from someone else.Так. Додайте підпис, ініціали й дату в тому самому сеансі або запросіть підпис в іншої людини.

Is editing free?Чи редагування безкоштовне?

A Free plan is available for basic edits. See pricing for what each plan includes.Для базового редагування є безкоштовний план Free. Що входить до кожного плану, дивіться на сторінці з цінами.
