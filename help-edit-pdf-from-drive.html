Follow these stepsВиконайте ці кроки

  1. In Google Drive, select the PDF and choose Open with → DocHub.У Google Drive виберіть PDF і натисніть «Відкрити за допомогою» → DocHub.

  2. Choose the editing tool: text, highlight, comment, draw or page management.Виберіть потрібний інструмент: текст, виділення, коментар, малювання чи керування сторінками.

  3. Review the document at normal size and check each page you changed.Перегляньте документ у звичайному масштабі й перевірте змінені сторінки.

  4. Save or export the completed copy using the options available in your account.Збережіть або експортуйте готову копію доступним у вашому акаунті способом.

Before you beginПеред початком

Keep an untouched original when the document is important. Visually covering text is not certified redaction; do not use whiteout to remove sensitive information.Якщо документ важливий, збережіть незмінений оригінал. Візуальне закриття тексту — це не сертифіковане редагування даних; не використовуйте замазування для видалення чутливої інформації.

What should I prepare first?Що підготувати спочатку?
