StepКрок 1 / 5

Open the PDF with DocHubВідкрийте PDF у DocHub

In Google Drive, select the PDF, then choose Open with → DocHub from the right-click menu or the top bar. The editor opens in a new tab with the page thumbnails on the side and the tools across the top. Check the file name in the header. If you need the original untouched, plan now to save your work as a separate copy.У Google Drive виберіть PDF і натисніть «Відкрити за допомогою → DocHub» у контекстному меню чи на верхній панелі. Редактор відкриється в новій вкладці: мініатюри сторінок збоку, інструменти вгорі. Перевірте назву файлу в заголовку. Якщо оригінал має лишитися незмінним, одразу плануйте зберегти роботу окремою копією.

StepКрок 2 / 5

Add or correct text on the pageДодайте чи виправте текст на сторінці

Pick the Text tool and click where the new words should go. Type, then adjust font size and colour so the text matches the lines around it. To replace an old value, cover it with Whiteout first and type the new one on top. Remember that whiteout only hides the old text visually.Оберіть інструмент «Текст» і клацніть там, де мають бути нові слова. Введіть текст, а потім налаштуйте розмір шрифту й колір, щоб він пасував до сусідніх рядків. Щоб замінити старе значення, спершу прикрийте його замазуванням, а зверху введіть нове. Пам’ятайте: замазування лише візуально приховує старий текст.

StepКрок 3 / 5

Highlight, comment, draw or add an imageВиділіть, прокоментуйте, намалюйте чи додайте зображення

Use Highlight on lines a reviewer must look at and Comment to explain why. Draw is handy for a quick arrow or circle on a diagram. To add a logo or a photo, choose Image and pick a file, then drag the corners to size it. Keep markups on separate lines from body text so they stay readable.Скористайтеся виділенням для рядків, на які має звернути увагу рецензент, і коментарем, щоб пояснити чому. Не накладайте позначки на основний текст, щоб усе лишалося читабельним.

Editing a Drive PDF without surprisesРедагування PDF із Google Drive без несподіванок

PDFs are built for sharing, not editing. These notes help you choose the right tool and keep the result clean.PDF створено для поширення, а не для редагування. Ці нотатки допоможуть обрати правильний інструмент і отримати охайний результат.

Choose the tool for the jobОберіть інструмент під завдання

Use the text tool to add new words, dates and initials. Use highlight, comments and drawing to review a document without changing its content. Use the page tools when the structure is wrong: merge files, reorder pages, add blank pages or delete extra ones. Picking the right tool first saves undoing later.Інструмент тексту — щоб додати слова, дати й ініціали. Виділення, коментарі й малювання — щоб переглянути документ, не змінюючи вмісту. Інструменти сторінок — коли не так зі структурою: об’єднайте файли, змініть порядок, додайте порожні чи видаліть зайві сторінки. Правильний інструмент із самого початку позбавляє скасувань.

Match the look of the pageДотримуйтеся вигляду сторінки

When you add text, place it on the line and keep the size close to the surrounding text. Check at normal zoom, because text can look aligned when zoomed in and slightly off at 100%. A clean result reads as part of the original document.Додаючи текст, ставте його на рядок і тримайте розмір близьким до навколишнього тексту. Перевіряйте у звичайному масштабі: у збільшеному вигляді текст може здаватися рівним, а на 100% — трохи зміщеним. Охайний результат читається як частина оригіналу.

Protect the originalБережіть оригінал

For contracts, applications and other important files, keep an untouched copy before you edit. Save the edited version under a new name so everyone knows which file is current. If several people edit, agree who saves the final copy.Для договорів, заяв та інших важливих файлів збережіть недоторкану копію перед редагуванням. Зберігайте відредаговану версію під новою назвою, щоб усі знали, який файл актуальний. Якщо редагують кілька людей, домовтеся, хто зберігає остаточну копію.

Know where editing stopsЗнайте межі редагування

Whiteout is visual cover, not certified redaction, so it is not suitable for removing sensitive information. Files up to 31 MB are supported. Some features depend on your plan; check the pricing page and the DocHub Help Center for current options.Замазування — це візуальне приховування, а не сертифіковане редагування, тож воно не підходить для видалення конфіденційної інформації. Підтримуються файли до 31 MB. Деякі функції залежать від тарифу; актуальні можливості дивіться на сторінці цін і в Довідковому центрі DocHub.

Pro tipsКорисні поради

  1. Make a copy in Drive before editing an important file.Зробіть копію в Google Drive, перш ніж редагувати важливий файл.
  2. Check every changed page at 100% zoom.Перевірте кожну змінену сторінку в масштабі 100%.
  3. Use comments for questions instead of editing someone else’s text.Ставте запитання в коментарях, а не правте чужий текст.
  4. Never use whiteout to hide sensitive data.Ніколи не приховуйте конфіденційні дані замазуванням.

Fix the most common editing problemsЯк виправити найпоширеніші проблеми з редагуванням

⚠ New text does not match the pageНовий текст не пасує до сторінки

Select the text box and change the font size and colour until it matches the lines around it. Zoom in to line it up with the baseline of the neighbouring text.Виділіть текстове поле й змінюйте розмір шрифту та колір, доки текст не пасуватиме до сусідніх рядків. Збільште масштаб, щоб вирівняти його по лінії сусіднього тексту.

⚠ You need to change existing wordsТреба змінити наявні слова

Cover the old words with Whiteout, then add new text on top in a matching size. For anything sensitive, remember whiteout does not remove the old text from the file.Прикрийте старі слова замазуванням і додайте зверху новий текст відповідного розміру. Якщо дані чутливі, пам’ятайте: замазування не видаляє старий текст із файлу.

⚠ The original was overwrittenОригінал перезаписано

⚠ Pages came out in the wrong order after a mergeПісля об’єднання сторінки стоять не в тому порядку

Open the page tools and drag the thumbnails into the right sequence. Check the page count before you save so nothing is duplicated or missing.Відкрийте інструменти сторінок і перетягніть мініатюри в правильній послідовності. Перед збереженням перевірте кількість сторінок, щоб нічого не задублювалося й не зникло.
