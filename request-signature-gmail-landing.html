GUIDEПОСІБНИК

How to request an e-signature from GmailЯк запросити електронний підпис із Gmail

Getting someone else to sign is mostly about preparation. A well-prepared request is signed faster and comes back right the first time.Щоб хтось інший підписав документ, головне — підготовка. Добре підготовлений запит підписують швидше, і він повертається правильним з першого разу.

Confirm the version firstСпершу перевірте версію

Before you add any fields, make sure the attachment is the final version. If the email thread has several drafts, open the latest one. Fill in details that should not be left to the signer, like dates of service or amounts. Once the request is out, changes mean starting again.Перш ніж додавати поля, переконайтеся, що вкладення — фінальна версія. Якщо в ланцюжку кілька чернеток, відкрийте останню. Заповніть дані, які не варто залишати підписантові, як-от дати надання послуг чи суми. Після надсилання запиту будь-яка зміна означає починати заново.

Place fields with careРозміщуйте поля уважно

Put a signature field on every line the signer must sign, and add date and initials fields where the document asks. Mark essential fields as required. Check every page, since initials are often needed in the middle of long documents. A clear layout means fewer questions from the signer.Поставте поле підпису на кожному рядку, де має підписати підписант, і додайте поля дати й ініціалів там, де цього вимагає документ. Позначте ключові поля як обов’язкові. Перевірте кожну сторінку: ініціали часто потрібні посередині довгих документів. Зрозуміле розташування — менше запитань від підписанта.

Choose signers and orderВиберіть підписантів і порядок

Enter each signer’s email address carefully; a typo sends the request to the wrong inbox. If one person must sign before another, set the signing order. For a single signer, order does not matter. Add a short message so the signer knows what the document is and why it matters.Уважно вводьте адресу кожного підписанта: одна помилка — і запит піде не туди. Якщо одна людина має підписати раніше за іншу, задайте порядок підписання. Для одного підписанта порядок не важливий. Додайте коротке повідомлення, щоб підписант розумів, що це за документ і навіщо він.

Track, review and storeВідстежуйте, перевіряйте й зберігайте

Check the status to see who has signed. When the document is complete, open it and confirm every field is filled. Review the audit trail if you need a record of the activity. Export the final copy to Google Drive and let the original sender know it is done.Перевіряйте статус, щоб бачити, хто вже підписав. Коли документ завершено, відкрийте його й переконайтеся, що всі поля заповнені. За потреби перегляньте журнал аудиту. Експортуйте фінальну копію в Google Drive і повідомте початкового відправника, що все готово.

FAQ

Frequently asked questionsПоширені запитання

Does the signer need the Gmail add-on?Чи потрібне підписантові доповнення для Gmail?

You need the add-on to send the request from Gmail. The signer receives the request by email; the exact steps they see depend on the current DocHub signing flow.Доповнення потрібне вам, щоб надіслати запит із Gmail. Підписант отримує запит електронною поштою; конкретні кроки, які він бачить, залежать від поточного процесу підписання в DocHub.

Where does the signed copy go?Куди потрапляє підписана копія?

It comes back to you in DocHub. From there you can export it to Google Drive or send it on.Вона повертається до вас у DocHub. Звідти її можна експортувати в Google Drive або надіслати далі.

Can I add more than one signer?Чи можна додати кількох підписантів?

Yes. Add each signer and set the signing order if they need to sign in sequence.Так. Додайте кожного підписанта й задайте порядок підписання, якщо вони мають підписувати по черзі.

How do I know when it is signed?Як дізнатися, що документ підписано?

Each request shows its status. When everyone has completed their part, the document is marked complete and the audit trail records the activity.Кожен запит показує свій статус. Коли всі виконали свою частину, документ позначається як завершений, а журнал аудиту фіксує дії.

Are there limits on signature requests?Чи є обмеження на кількість запитів?

Yes, plan limits apply. See pricing for the current limits on Free, Basic and Pro.Так, діють обмеження плану. Актуальні ліміти для Free, Basic і Pro дивіться на сторінці з цінами.

What if I need to send the same file to many people?А якщо треба надіслати той самий файл багатьом?

Use bulk send, a Pro-plan feature. Each recipient gets their own copy to sign.Скористайтеся масовим надсиланням — це функція плану Pro. Кожен отримувач отримує власну копію для підпису.

Can I sign the document myself as well?Чи можу я теж підписати документ?

Yes. Add your own signature before sending, or include yourself as one of the signers in the order you need.Так. Поставте свій підпис до надсилання або додайте себе як одного з підписантів у потрібному порядку.

Does the original sender see the request?Чи бачить запит початковий відправник?

Only if you add them as a signer. Otherwise, reply to their thread with the completed document when it is done.Лише якщо ви додасте його як підписанта. Інакше відповідайте в його ланцюжку із завершеним документом, коли все буде готово.
