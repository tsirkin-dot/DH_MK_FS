Planning a DocHub rollout in Google WorkspaceЯк спланувати впровадження DocHub у Google Workspace

A domain install is quick; a good rollout takes a little planning. Here is how to decide who gets DocHub, what to check before you install and how to make sure people reach a completed first task.Встановлення на домен — справа швидка, а вдале впровадження потребує трохи планування. Ось як вирішити, хто отримає DocHub, що перевірити перед встановленням і як переконатися, що люди виконають перше завдання.

Decide the scopeВизначте охоплення

List the groups that actually handle documents: teachers, office staff, HR, sales. Map them to organizational units in your Admin console. Install for those units first rather than the whole domain if some groups, like students, don’t need DocHub. You can expand later.Перелічіть групи, які справді працюють із документами: учителі, канцелярія, відділ кадрів, продажі. Зіставте їх з організаційними підрозділами в консолі адміністратора. Якщо деяким групам, наприклад учням, DocHub не потрібен, встановіть його спершу для потрібних підрозділів, а не для всього домену. Охоплення можна розширити пізніше.

Review access and policyПеревірте доступ і політику

Before confirming, read the data access the app requests in the install screen. Check it against your organization’s security and privacy policy. If a separate team approves apps, involve them early. Google’s admin help is the current reference for menu names and steps.Перш ніж підтвердити, прочитайте на екрані встановлення, до яких даних застосунок запитує доступ. Звірте це з політикою безпеки й приватності вашої організації. Якщо застосунки погоджує окрема команда, залучіть її заздалегідь. Актуальні назви меню й кроки — у довідці Google для адміністраторів.

Separate install from licensingВідокремте встановлення від ліцензування

Installing DocHub doesn’t give everyone a paid plan. Decide separately which plan fits: Free, Basic, Pro or Site License. Site License is the plan for schools and organizations. See the pricing page for current details.Встановлення DocHub не надає всім платний план. Окремо вирішіть, який план підходить: Free, Basic, Pro чи Site License. Site License — план для шкіл і організацій. Актуальні умови — на сторінці цін.

Help people finish a first taskДопоможіть виконати перше завдання

Tell users where DocHub now appears: “Open with → DocHub” in Drive, the add-on in Gmail and the Classroom integration. Point them to one concrete task, such as signing a PDF from Drive or sending a permission slip. Measure the first completed task, not just installs. Share the relevant how-to pages.Повідомте користувачам, де тепер з’явився DocHub: «Відкрити за допомогою → DocHub» у Drive, доповнення в Gmail та інтеграція з Classroom. Запропонуйте одне конкретне завдання, наприклад підписати PDF із Drive чи надіслати згоду батькам. Оцінюйте перше виконане завдання, а не лише кількість встановлень. Поділіться відповідними інструкціями.

Pro tipsКорисні поради

  2. Allow time for Google to propagate the change.Дайте Google час поширити зміни.
  3. Send users a short note on where DocHub appears.Надішліть користувачам коротку примітку, де з’явився DocHub.
  4. Decide on the plan separately from the install.Вирішуйте щодо плану окремо від встановлення.
