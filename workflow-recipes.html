GUIDEПОСІБНИК

How to choose and run a document workflow recipeЯк обрати й виконати сценарій роботи з документами

A recipe is a short, repeatable path from a starting document to a finished one. Here is how to pick one, what the fourth recipe looks like and when a recipe isn’t the right tool.Сценарій — це короткий повторюваний шлях від вихідного документа до готового. Ось як його обрати, як виглядає четвертий сценарій і коли сценарій не підходить.

Start from where the document livesВідштовхуйтеся від того, де лежить документ

The fastest recipe is the one that starts where your document already is. If it’s in a shared Drive folder, start with the Drive contract recipe. If it arrived in Gmail, use the Gmail recipe. If it goes to a class, use the Classroom recipe. If you send it every week, use a template.Найшвидший сценарій — той, що починається там, де вже лежить документ. Якщо він у спільній папці Drive, почніть зі сценарію договору з Drive. Якщо прийшов у Gmail — сценарій для Gmail. Якщо йде класу — сценарій для Classroom. Якщо надсилаєте щотижня — шаблон.

Recipe: one template to many recipientsСценарій: один шаблон — багато адресатів

For HR, sales or admin teams sending the same document. Save the document as a template, use bulk send to reach every recipient and track who has completed it. Bulk sending is a Pro feature, so check pricing before you plan a large send. Each recipient gets their own clean copy.Для кадрових служб, відділів продажів чи адміністрації, які надсилають той самий документ. Збережіть документ як шаблон, скористайтеся масовою розсилкою, щоб охопити всіх адресатів, і стежте, хто вже завершив. Масова розсилка — функція Pro, тож перед великою розсилкою перегляньте сторінку цін. Кожен адресат отримує власну чисту копію.

Check the limits before you rely on itПеревірте обмеження, перш ніж покладатися

Each recipe lists its limits. The Gmail recipe needs the add-on installed. The Classroom recipe depends on how your school’s Google account is set up. Signing and bulk-send recipes depend on your plan. Reading the limits first saves a surprise halfway through.Для кожного сценарію вказано обмеження. Сценарій для Gmail потребує встановленого додатка. Сценарій для Classroom залежить від налаштувань Google у вашій школі. Сценарії з підписанням і масовою розсилкою залежать від плану. Якщо прочитати обмеження заздалегідь, посеред процесу не буде несподіванок.

When a recipe is not the right fitКоли сценарій не підходить

If you need an automation that moves data across many apps, use an integration platform instead. If a document must be redacted, not just visually covered, DocHub’s whiteout is not a certified redaction tool. Recipes are for people doing the work by hand, faster, with fewer handoffs.Якщо потрібна автоматизація, що переносить дані між багатьма застосунками, скористайтеся платформою інтеграцій. Якщо документ потрібно знеособити, а не просто візуально замазати, пам’ятайте: замазування в DocHub не є сертифікованим знеособленням. Сценарії — для людей, які виконують роботу самі, але швидше й з меншою кількістю передач.
