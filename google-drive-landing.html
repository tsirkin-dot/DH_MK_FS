GUIDEПОСІБНИК

Choosing the right Drive routeЯк обрати правильний сценарій для Drive

Every Drive task in DocHub starts the same way: open the file with DocHub. What happens next depends on what the document needs. Use this guide to pick one of three routes and twelve narrow tasks.Кожне завдання з Drive у DocHub починається однаково: відкрийте файл у DocHub. Що далі — залежить від того, що потрібно документу. Цей посібник допоможе обрати один із трьох сценаріїв і дванадцяти вузьких завдань.

Edit: when the content is wrong or missingРедагування: коли вміст хибний чи неповний

Choose the edit route when you need to change what’s on the page. Narrow tasks include whiting out text, adding text or a date, merging PDFs, and reordering or deleting pages. Whiteout covers text visually and is not a certified redaction, so don’t rely on it to remove sensitive data. Export the edited copy back to Drive when you finish.Обирайте редагування, коли треба змінити те, що на сторінці. Вузькі завдання: замазати текст, додати текст чи дату, об’єднати PDF, змінити порядок чи видалити сторінки. Замазування приховує текст лише візуально й не є сертифікованим видаленням, тож не покладайтеся на нього для чутливих даних. Коли закінчите, експортуйте відредагований файл назад у Drive.

Sign: when a signature is the goalПідпис: коли мета — підпис

Choose the sign route when you or someone else must sign. Add initials, set an order for several signers, sign a lease or keep the audit trail with the file. Status tracking shows who has signed and who is next. Rules for e-signatures vary by document and place; this is not legal advice.Обирайте підписання, коли підписати маєте ви чи хтось інший. Додайте ініціали, задайте порядок для кількох підписантів, підпишіть договір оренди чи збережіть журнал аудиту разом із файлом. Відстеження статусу показує, хто вже підписав, а хто наступний. Вимоги до електронних підписів залежать від документа й країни; це не юридична консультація.

Forms: when other people fill it inФорми: коли заповнюють інші

Choose the forms route when the same document goes to many people. Add checkboxes, dropdowns and required signature fields, then save it as a reusable template. You can also share a form by link. Required fields help you get complete answers the first time.Обирайте форми, коли той самий документ отримують багато людей. Додайте прапорці, списки й обов’язкові поля для підпису, а потім збережіть файл як шаблон. Форму можна поширити й за посиланням. Обов’язкові поля допомагають отримати повні відповіді з першого разу.

Rolling it out to a teamЯк запровадити для команди

Each person who edits or signs connects DocHub once. A Workspace administrator can also install it for the whole domain, which is easier for schools and larger teams. Organizations add roles and permissions. Colleagues who only view files don’t need DocHub at all.Кожен, хто редагує чи підписує, підключає DocHub один раз. Адміністратор Workspace також може встановити його для всього домену — це зручніше для шкіл і великих команд. Organizations додають ролі та дозволи. Колегам, які лише переглядають файли, DocHub не потрібен.

FAQ

Frequently asked questionsПоширені запитання

Does the file leave Drive?Чи покидає файл Drive?

DocHub opens the file to do the task. You export the finished copy back to Drive, usually to the same folder.DocHub відкриває файл, щоб виконати завдання. Готову копію ви експортуєте назад у Drive, зазвичай у ту саму папку.

How do I connect DocHub to Drive?Як підключити DocHub до Drive?

Right-click a PDF, choose Open with → Connect more apps and add DocHub. After that, DocHub appears in the Open with menu.Клацніть правою кнопкою на PDF, оберіть «Відкрити за допомогою → Підключити інші застосунки» й додайте DocHub. Після цього він з’явиться в меню.

Do my colleagues need DocHub?Чи потрібен DocHub моїм колегам?

Only those who edit or sign in DocHub. Everyone else sees the file in Drive as usual.Лише тим, хто редагує чи підписує в DocHub. Решта бачить файл у Drive, як завжди.

Can an admin install it for everyone?Чи може адміністратор встановити його для всіх?

Yes. A Workspace administrator can install DocHub for the domain. See the domain install guide for the steps.Так. Адміністратор Workspace може встановити DocHub для домену. Кроки описані в інструкції зі встановлення на домен.

What’s the file-size limit?Яке обмеження на розмір файлу?

DocHub works with files up to 31 MB. Split or compress larger files before opening them.DocHub працює з файлами до 31 МБ. Більші файли розділіть чи стисніть перед відкриттям.

Is whiteout the same as redaction?Замазування — це те саме, що видалення даних?

No. Whiteout hides text visually but is not certified redaction. Don’t use it to remove confidential information.Ні. Замазування приховує текст візуально, але не є сертифікованим видаленням. Не використовуйте його, щоб прибрати конфіденційну інформацію.

Which tasks are free?Які завдання безкоштовні?

The Free plan covers basic workflows. Features such as bulk sending and AI tools are part of Pro; see pricing.План Free покриває базові сценарії. Масове надсилання та AI-інструменти входять у Pro; деталі — на сторінці цін.

Can I work with files outside Drive?Чи можна працювати з файлами поза Drive?

Yes. You can upload a file, and DocHub also integrates with Dropbox, Box and OneDrive.Так. Файл можна завантажити, а ще DocHub інтегрується з Dropbox, Box і OneDrive.
