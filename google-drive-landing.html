QuestionsПитання

Does the file leave Drive?Чи залишає файл Drive?

DocHub opens it for the task; you export the finished copy back to Drive.DocHub відкриває його для задачі; готову копію ви експортуєте назад у Drive.

Do my colleagues need DocHub?Чи потрібен колегам DocHub?

Only those who edit or sign in DocHub; others just see the file in Drive.Лише тим, хто редагує чи підписує в DocHub; решта бачить файл у Drive.

Can an admin install it for everyone?Чи може адмін встановити для всіх?

Yes, see the domain install guide.Так, див. інструкцію зі встановлення на домен.

Questions and answersЗапитання та відповіді

What should I prepare first?Що підготувати спочатку?
